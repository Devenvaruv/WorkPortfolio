# Project Media Requirements

The portfolio currently uses available videos for Road Asset Detection, Oakland Data Explorer, and Here2Stay. The projects below need dedicated media assets. Add files at the listed paths, then update the matching `media` field in `src/portfolioData.js`.

## InterviewWithAI

- Required location: `public/videos/interviewwithai-demo.mp4`
- Backup image location: `public/images/interviewwithai-dashboard.png`
- Requirement: 20-40 second product walkthrough showing the voice interview flow, coding workspace with Monaco Editor, transcript capture, and AI feedback screen.

## Codex Session Visualizer

- Required location: `public/videos/codex-session-visualizer.mp4`
- Backup image location: `public/images/codex-session-visualizer.png`
- Requirement: VS Code screen recording showing file/folder labels for Found, Read, Edited, Created, Deleted; parsed session logs; and the multi-agent graph view.

## A2A Multi-Agent Builder

- Required location: `public/videos/a2a-builder-demo.mp4`
- Backup image location: `public/images/a2a-builder.png`
- Requirement: Demo of creating or selecting agents, versioning prompts/configs, running an orchestrated workflow, and viewing execution logs or rollback state.

## 10-Agent AI Board Game Simulation

- Required location: `public/videos/ai-board-game-simulation.mp4`
- Backup image location: `public/images/ai-board-game-simulation.png`
- Requirement: Short gameplay capture showing the Dungeon Master, player agents, dialogue/action sub-agents, JSON action output, and shared board state updates.

## Catalog Intelligence Automation

- Required location: `public/videos/catalog-intelligence.mp4`
- Backup image location: `public/images/catalog-intelligence.png`
- Requirement: Before/after walkthrough showing a furniture catalog page, extracted structured JSON, detected product images, and linked product records.

## LLM-Powered Data Retrieval Chatbot

- Required location: `public/videos/llm-sql-chatbot.mp4`
- Backup image location: `public/images/llm-sql-chatbot.png`
- Requirement: Demo showing a natural-language infrastructure question, generated SQL or query trace, returned device usage/memory data, and dashboard result.
