# Deven Varu Portfolio

React portfolio site for showcasing AI engineering work across production AI products, multi-agent systems, A2A infrastructure, voice agents, RAG, and computer vision.

## Structure

- `src/App.js` - main portfolio UI, layout, filtering, and styled-components styles.
- `src/portfolioData.js` - profile, highlights, projects, experience, skills, and awards.
- `public/videos/` - available project videos used by the portfolio.
- `public/images/` - shared static image assets.
- `PROJECT_MEDIA_REQUIREMENTS.md` - missing video and screenshot requirements for project-specific media.
- `SEO.md` - SEO architecture, generated project pages, sitemap, robots, and deployment checklist.

## Commands

```bash
npm install
npm start
npm run seo:generate
npm run build
```

The local development server runs at `http://localhost:3000`.
